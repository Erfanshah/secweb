**SecToolKit** یک مجموعه‌ی قدرتمند از ابزارهای خط فرمان برای تست نفوذ و امنیت سایبری است. این ابزار با هدف آموزش و استفاده‌ی اخلاقی طراحی شده است.

---

## ✨ ویژگی‌ها

- **🕵️ XSS Scanner**: اسکنر آسیب‌پذیری‌های XSS با ۱۲ پیلود مختلف
- **🗄️ SQLi Scanner**: تشخیص تزریق SQL با الگوهای خطا
- **🌐 Port Scanner**: اسکن سریع پورت با قابلیت همزمانی (asyncio)
- **🔑 Password Cracker**: کرک هش‌های MD5، SHA1 و SHA256 با دیکشنری
- **📊 Log Analyzer**: تحلیل لاگ‌های آپاچی و Nginx برای تشخیص حملات
- **🎨 خروجی رنگی**: نمایش نتایج با رنگ‌های جذاب برای خوانایی بهتر
